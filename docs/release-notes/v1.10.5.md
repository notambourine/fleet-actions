## Heads-up: zizmor 1.31 flags `issue_comment` and installs from PyPI

The `zizmor` gate now runs zizmor 1.31.1. The `dangerous-triggers` audit now reports every
workflow triggered by `issue_comment`, so a repository that passed before can fail now. Move
the workflow to a safer trigger, or add a zizmor ignore with the reason.

The cache-poisoning audit now reads `cache-mode:`. It skips jobs set to `none` and reports
`write` or `write-only` on dangerous triggers.

zizmor no longer runs in a Docker image. The runner needs `python3` with pip and network
access to `pypi.org` and `files.pythonhosted.org`. GitHub-hosted and Blacksmith Ubuntu runners
already have both. No inputs changed.
