## Heads-up: zizmor audits the whole repository

The `zizmor` gate now audits the repository root instead of `.github/workflows` alone. It
picks up composite actions (`action.yml` anywhere outside `.gitignore`), `dependabot.yml`, and
`.pre-commit-config.yaml`, so a repository that passed before can fail now.

Nothing changes until your repository moves its `fleet-ci` pin to this release. The pull request
that moves the pin runs the new gate, so make the fixes below on that branch before you merge it.

Expect `dependabot-cooldown` first: zizmor wants `cooldown.default-days` of at least 7 on every
stanza. Security updates ignore cooldown, so CVE fixes still open at once. Exempt repos you own
so their releases skip the wait:

```yaml
    cooldown:
      default-days: 7
      exclude:
        - notambourine/*   # '@notambourine/*' on npm stanzas
```

Fix or ignore anything else it reports. To keep the old scope while you work through findings, set
`zizmor-inputs: .github/workflows` on your `fleet-ci` call.
