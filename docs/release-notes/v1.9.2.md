## Heads-up: betterleaks 1.9.0 adds 46 detection rules

The `betterleaks` gate now runs betterleaks 1.9.0. New rules cover Miro, VoyageAI, and
Bitbucket Data Center tokens, among others, so a history that passed before can fail now.

If the gate fails after you move to this release, rotate any live secret it reports. For a false
positive, add an entry to your repository's betterleaks allowlist. No inputs changed.
